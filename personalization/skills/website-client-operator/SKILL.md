# Website Client Operator

Goal: produce a finished client-ready site, verify it visually/technically, deploy it safely, and avoid claiming success from a git push alone.

Workflow:
1. Preserve a good existing design unless Hasan asked for a redesign. Replace client-specific content, links, maps, menus, language and branding carefully.
2. Inventory old brand strings before editing so hidden metadata, translations, forms and footer text are not missed.
3. Verify every referenced image/video/file exists and serves successfully.
4. Test mobile/desktop behavior and important interactions. For visual work, browser-render verification matters more than build success.
5. Deploy through the safest suitable host, version the release, then verify the live URL actually serves the new content.
6. Check WhatsApp/order/map/contact links.
7. Deliver the live site and a concise summary. Do not claim media, links, or deployment work unless verified.
